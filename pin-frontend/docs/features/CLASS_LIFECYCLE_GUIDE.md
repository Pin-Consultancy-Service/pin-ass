## 🎥 **Recording Behavior**

### How Recordings Work:

1. **During Live Class**: No recording shows (students should join live!)

2. **After Class - Attended**: 
   - Message: "Recording Available Soon"
   - Recording appears when instructor uploads it
   - Student can review what they learned

3. **After Class - Missed**:
   - Recording **AUTOMATICALLY displays**
   - Student doesn't need to search for it
   - Encourages catching up on missed content

### Recording Sources:

In your current test:
- **Google Drive video**: Already embedded (`1rql2StA9ewhda7csHk98aKyl5vvtjiiK`)
- **Future**: Google Meet auto-records and uploads to Drive
- **Backend will**: Automatically fetch recording URL after meeting ends

## 🔧 **Technical Details**

### Status Determination:

```typescript
// Class is LIVE when:
isLive = (now >= scheduledTime - 15min) && (now <= scheduledTime + duration)

// Example:
// Scheduled: 2:30 PM, Duration: 45 min
// Live window: 2:15 PM - 3:15 PM (1 hour window)
```

### Recording Display Logic:

```typescript
// Show recording if:
isMissed = (status === "completed") && (attendance === "absent") && (recordingUrl exists)
```

### Automatic Updates:

- Countdown timer: Updates every 60 seconds
- Status checks: Every 60 seconds
- Manual refresh: Always gets latest state

## 💡 **For Instructors**

### What You Do:

1. **Before Class**:
   - Create Google Meet with scheduled time
   - Share meet link with us (we add to system)
   - Students see countdown

2. **During Class**:
   - Start the meeting at scheduled time
   - Students click green "Join" button
   - They join your meeting instantly

3. **After Class**:
   - Google Meet auto-records (if enabled)
   - Recording uploads to Google Drive
   - Backend fetches recording URL
   - Students who missed see it automatically

### What Students Do:

1. **Before**: Download materials, see countdown
2. **During**: Click green button → join meeting
3. **After**: Watch recording if they missed it
