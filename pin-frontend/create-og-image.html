📸 How to Create Your OG Image

  1. Take a screenshot of the blue image above (use Windows Snipping Tool or Snip & Sketch)
  2. Crop to exactly 1200x630 pixels (the blue box)
  3. Save as og-image.png
  4. Move to pin-frontend/public/og-image.png
  5. Build and deploy your site
  6. Test by sharing your link on WhatsApp/Twitter

🎨 Better Option: Use Canva

  1. Go to Canva.com
  2. Search for "Facebook Post" template (1200x630px)
  3. Use this design as reference
  4. Upload your actual PIN logo
  5. Match the colors and layout
  6. Download as PNG and save to public/og-image.png
